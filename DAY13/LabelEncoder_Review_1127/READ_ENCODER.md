# LabelEncoder 이전 대응표 복습

10문항 전용 세트입니다. CSV는 이미 학습용과 검증용으로 구분했습니다. 전체 분류/회귀 모의시험이 아니므로 기존 24문항과 독립적으로 풀면 됩니다.

1. LabelEncoder_practice.ipynb를 열고 1번부터 순서대로 실행하세요.
2. 4번과 10번은 의도적으로 잘못된 방식을 관찰하는 제공 코드입니다. 빈 answer 변수만 작성하세요. 나머지 문제는 빈 코드 셀입니다.
3. 5번에서 원본 train으로 다시 시작하므로 4번의 잘못된 변환을 이후 모델 입력으로 사용하지 않습니다.
4. 정답은 LabelEncoder_solutions.ipynb에 실행 결과와 함께 있습니다.

핵심:
- saved_le = le는 복사가 아닙니다. 같은 객체에 fit을 다시 하면 saved_le의 대응표도 바뀝니다.
- le = LabelEncoder()로 새 객체를 할당하는 것과 le.fit(...)으로 기존 객체를 재학습하는 것은 다릅니다.
- 여러 컬럼이면 반복문 안에서 새 인코더를 만들고 encoders[col]에 저장합니다.
- encoders["airline"]로 예전에 학습한 인코더를 꺼내 transform 또는 inverse_transform합니다.
- 파일을 불러오는 것은 joblib.load입니다. fit은 불러오기가 아니라 대응표 학습입니다.
- 검증에는 transform만 사용합니다. 검증에서 일부 범주가 빠지면 fit_transform은 번호를 달리 부여할 수 있습니다.
- LabelEncoder의 주된 용도는 정답 라벨 y입니다. 범주형 피처에는 순서 없는 정수 코드가 인위적 순서로 해석될 수 있어 원핫 등을 고려합니다. 이 세트는 모의문제에서 접한 여러 열의 LabelEncoder 사용과 객체 보관을 복습하기 위한 것입니다.
